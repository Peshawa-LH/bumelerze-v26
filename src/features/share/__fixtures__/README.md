# Share-card fixtures

`bml202602ia.bands_mi.json` is the real `bands_mi.json` of Bumelerze Atlas event
`bml202602ia`, version 2 (an M3.2 earthquake in north-western Iran, 5 Oct 2026),
byte-identical to the published file. It is small (10 KB), its largest band
reaches only level IV, and it has the model-grid rectangle as its lowest band,
which makes it a good test of the card's band selection and framing.
