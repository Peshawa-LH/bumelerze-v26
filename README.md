# Bumelerze

Earthquake monitoring app for Kurdistan — live event feed, "did you feel it?" community
reports, ShakeMaps, and safety information, in Kurdish (Sorani + Kurmanji), Arabic, and
English. *Bûmelerze* is the Kurdish word for earthquake.

**Status: Phase 0 — design.** No app code yet. The project brain lives in `PROJECT.md` and
`docs/` — see the design log for the current state.

Planned stack (proposed): Expo (React Native) + TypeScript · Supabase · USGS/EMSC feeds ·
MapLibre GL. See `docs/decisions.md`.
