# Bumelerze

Earthquake monitoring app for Kurdistan — live event feed, "did you feel it?" community
reports, ShakeMaps, and safety information, in Kurdish (Sorani + Kurmanji), Arabic, and
English. *Bûmelerze* is the Kurdish word for earthquake.

**Website:** <https://bumelerze.com> · **App (web build):** <https://bumelerze.com/app> ·
**Contact:** <hello@bumelerze.com>

**Status: in development.** The app is not yet in the app stores; the web build
above is an interim preview. Design and decision records are maintained outside
this repository.

Stack: Expo (React Native) + TypeScript · Supabase · USGS/EMSC feeds ·
MapLibre GL.
