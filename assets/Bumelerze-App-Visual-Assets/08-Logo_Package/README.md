# Bumelerze Final Logo Package

This package combines the selected **signal-red color system** from `01f-a-tapered-signal-red` with the approved **two-peak mountain/seismic waveform** shared by `01g-signal-red`, `01h-burgundy-sand`, and `01j-burnt-orange`. The complete visible silhouette was vectorized from `01g` and refined into a continuous quadratic Bézier contour for clean output at every zoom level.

## Start here

- Use `SVG/bumelerze-primary-horizontal.svg` for most scalable applications.
- Use `SVG/bumelerze-app-icon-square.svg` as the master application icon. Platform stores apply their own corner masks.
- Use `PNG/bumelerze-primary-horizontal-1800.png` when SVG is unsupported.
- Use `App-Icons/` for ready-sized application and favicon artwork.
- Consult `Brand-Info/brand-guidelines.md` before resizing, recoloring, or placing the logo.

## Folder guide

- **SVG** — resolution-independent master artwork; wordmarks are outlined.
- **PNG** — transparent or presentation-ready raster exports.
- **App-Icons** — square, round, favicon PNG, SVG, and ICO assets.
- **Brand-Info** — palette, clear-space, minimum-size, and usage guidance.
- **Design-Tokens** — machine-readable color values.
- **Preview** — quick visual reference board.
- **Reference-Selections** — the two approved exploration sheets used to define this final system.
