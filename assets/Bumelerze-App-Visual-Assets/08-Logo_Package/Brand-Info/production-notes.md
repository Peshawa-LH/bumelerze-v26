# Production Notes

## Master artwork

SVG files are the source of truth. PNG files are convenience exports and should not be enlarged beyond their native pixel dimensions.

## Transparency

Primary horizontal, stacked, symbol, round-icon, and monochrome PNG files retain transparency where appropriate. Square application icons intentionally use an opaque signal-red background.

## Small-size testing

The seismic portion contains fine detail. Always inspect the final rendered size, especially at 16–32 px. Use the supplied favicon files rather than shrinking the horizontal logo.

## Print

Convert the SVG to the printer's requested PDF/X or EPS workflow using their output profile. CMYK conversions should be proofed because signal red and endpoint gold vary between coated and uncoated stock.

## Trademark note

This is an artwork production package, not a trademark clearance opinion. Conduct the appropriate name and symbol searches before formal registration or large-scale commercial use.
