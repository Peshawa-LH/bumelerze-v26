scripts/run_halabja.py`), the D20 gate (`docs/decisions.md` D20;
`docs/research/gmpe-set-proposal-v2.md` §7): our bare, unconditioned

equivalent pytest wrapper (`tests/test_halabja_smoke.py`, `@pytest.mark.slow`)

gate on the D20 verdict itself (a legitimate FAIL is not a test failure;
see that file's docstring and `REPORT.md`'s framing section).

## Wave D — the CONDITIONED re-judgment (`docs/decisions.md` "D20
smoke-test checkpoint outcome", 2026-08-06)

The bare-prior comparison above FAILED bias (both IMTs) and PGV coverage.
Peshawa's ruling: condition our own prior on the SAME Atlas DYFI
observations via our own `mvn.py`, then re-judge — a like-for-like
"conditioned vs. conditioned" comparison instead of "bare vs. conditioned".
Generated by `scripts/run_halabja_conditioned.py`
(`./.venv/bin/python scripts/run_halabja_conditioned.py`):

- `REPORT-CONDITIONED.md` — the re-judgment: bare-prior-vs-conditioned D20
  table, distance-binned nuance, the full sensitivity grid (GMICE model /
  nresp floor / observation-domain choices), the DYFI-observation
  "doughnut", and the circularity caveat. **Start here.**
- `results-conditioned.json` — the same numbers, machine-readable, for
  every sensitivity variant plus the wave-C bare-prior baseline inlined for
  diffing.
- `ems_map_conditioned.png` — the CONDITIONED (primary-variant) EMS-98 map.
- `residual_map_conditioned.png` — ln-PGA residual (conditioned − USGS).
- `distance_binned_bias_before_after.png` — bare (wave C) vs. conditioned
  (wave D) PGA/PGV ln-bias by distance bin, side by side.

Headline: the PRIMARY conditioned variant (Worden/MMI GMICE, nresp>=3,
observations restricted to our own grid's magnitude-scaled domain) PASSES
all four D20 criteria. Every alternative choice (Zanini/EMS GMICE,
nresp>=2, or an unrestricted global observation domain) is also computed
and reported — some fail — so the pass is shown as real but not
knife-edge-fragile-proof; read `REPORT-CONDITIONED.md`'s own sensitivity
grid and circularity-caveat sections before treating this as a clean bill
of health. Re-run: `./.venv/bin/python scripts/run_halabja_conditioned.py`
(reuses `run_halabja.py`'s cached Atlas products plus its own cached
`dyfi_geo_10km.geojson`, same `.cache/halabja/` directory, not committed).
The pytest wrapper (`tests/test_halabja_conditioned_smoke.py`,
`@pytest.mark.slow`) DOES assert the primary variant's D20 pass this time
(the task's specific headline outcome, not just harness well-formedness —
see that file's own docstring for why this differs from the bare-prior
smoke test's policy).
