# D20 Halabja smoke test — outputs

Generated by `scripts/run_halabja.py` (`./.venv/bin/python
scripts/run_halabja.py`), the D20 gate (`docs/decisions.md` D20;
`docs/research/gmpe-set-proposal-v2.md` §7): our bare, unconditioned
`gmpe_forward` prior vs. USGS's station+DYFI-conditioned Atlas ShakeMap for
the 2017 M7.3 Halabja/Sarpol-e Zahab earthquake (`us2000bmcg`).

- `REPORT.md` — the human-readable verdict, per criterion, plus
  interpretation. **Start here.**
- `results.json` — the same numbers, machine-readable (stats + config +
  versions), for anyone re-running the comparison later and diffing.
- `ems_map.png` — our forward EMS-98 map.
- `residual_map.png` — ln-PGA residual (ours − USGS) at every compared
  USGS grid cell.
- `distance_binned_bias.png` — PGA/PGV ln-bias by distance bin, with the
  D20 ±0.3 threshold lines.

Re-run: `./.venv/bin/python scripts/run_halabja.py` from `shake-service/`
(fetches and caches USGS's Atlas products under `.cache/halabja/` — not
committed, ~27 MB — on first run; instant on subsequent runs). The
equivalent pytest wrapper (`tests/test_halabja_smoke.py`, `@pytest.mark.slow`)
asserts the pipeline runs and produces well-formed numbers — it does not
gate on the D20 verdict itself (a legitimate FAIL is not a test failure;
see that file's docstring and `REPORT.md`'s framing section).
